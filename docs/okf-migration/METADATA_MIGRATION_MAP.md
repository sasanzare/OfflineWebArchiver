# Metadata Migration Map

## Scope

This field-level ledger maps current manifest, registry, Markdown, evidence, phase, relationship, and validation metadata to the frozen future contract. It performs no transformation. A blank official destination means the data is extension-only, body content, generated output, or deprecated.

## Reconciliation

The ledger contains **48** mutually distinct current field/pattern rows. All nine current allowed status values appear in rows 31-39; all registry item properties appear in rows 10-26 and 40-45; all manifest fields appear in rows 1-9 and 40. No row authorizes a Phase 3 transformation.

Owner decisions are needed only if a future actual `DEPRECATED` or `NOT_APPLICABLE` record lacks the authority evidence required by its existing status model. Neither blocks the deterministic Phase 4 core migration because no current record uses those values.
