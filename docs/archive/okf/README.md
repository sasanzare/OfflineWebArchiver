# Archived OKF material

This archive contains completed OKF bootstrap and migration material that is
useful for historical traceability but is no longer part of the active
maintenance workflow.

Archived files are non-authoritative. Do not use them as active configuration,
validator inputs, current path maps, or instructions for new changes. The
official bundle is under [`okf/`](../../../okf/index.md), project-specific
extensions are under [`okf-extension/`](../../../okf-extension/README.md), and
current maintainer instructions are in the
[OKF maintainer guide](../../../docs/okf-conformance/MAINTENANCE_GUIDE.md).

The archive is organized as follows:

- [`bootstrap/`](bootstrap/): the former root-level OKF bootstrap evidence and
  planning material.
- [`migration/`](migration/): completed migration plans, audits, reports,
  schemas, and handoff records.

Historical files retain their original claims and may contain references to
paths that existed at the time. The archive is checked for readability, while
historical relative links are not treated as active documentation failures.
Git history remains the ultimate historical record for every change.
