## Resolution rules

1. The row owner records evidence and proposed outcome.
2. Outcomes that change project architecture, security, privacy, release, or
   product governance also update `OD-026` and receive an ADR or main project
   decision reference as appropriate.
3. Related bootstrap/canonical schemas, validation, migration, risks, DoD,
   traceability and phase records change together.
4. The question ID and recommendation history remain traceable after resolution.
