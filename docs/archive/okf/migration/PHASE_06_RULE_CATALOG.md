# Phase 6 Rule Catalog

Official rules validate Concept frontmatter and non-empty type, root-index metadata, directory-index frontmatter absence, log heading structure, and unknown Markdown classification. Repository policy validates taxonomy, required fields, lifecycle, title/H1 equality, tags, sources, source IDs, portable paths, freshness, `owa`, and canonical order. Extension validation preserves manifest, registry, evidence, relationship, phase, and path-safety checks through the retained validator.

Quality and format findings are warnings. Cross-file registry requirements remain extension checks; link integrity is quality analysis.
