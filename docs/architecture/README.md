# Production Architecture

## Product Phase 16 Worker Pool over the Phase 8–15 foundation

The current architecture adds Phase 15 proxy policy and Phase 16 Worker Pool/rate-limit scheduling to the existing Playwright and Secret Store boundaries. Archive Core owns proxy identity, eligibility, Worker reservation, Origin budgets, cooldowns, affinity, and circuit breaking. Application Service remains the orchestration boundary and resolves credentials only through scoped Secret Store access. Browser Runtime owns Playwright, Context lifecycle, and request permits. SQLite schema 11 stores proxy metadata plus Project/Run/Origin scheduler state without raw credentials; transport contract 1.11 remains metadata-only. The Phase 10 foundation adds Interaction Profile/Plan/Trace schema 1 and bounded browser interaction. Product Phase 11 adds Secret Reference/Vault/Envelope version 1, a dedicated encrypted store, scoped access, redaction, safe exports, diagnostics, and temporary cleanup. Product Phase 12 adds Session metadata/storage-state/affinity schema 1, headed user-driven login, protected Storage State, fresh restore validation, explicit reauthentication, and safe CLI/Desktop controls. Product Phase 13 adds the all-request authentication allowlist, separate Crawl Run state, versioned replay/offline and Service Worker policies, canonical path/symlink boundaries, command allowlisting, concurrency contracts, and acceptance metrics. Product Phase 14 adds the versioned Locator/Login Flow contract, temporary page-local Picker, and visible OTP state machine without SMS/CAPTCHA automation or sensitive persistence. Product Phase 15 adds protocol-aware proxy metadata, Secret Store-backed credentials, health/cooldown eligibility, real Browser Runtime connectivity checks, and explicit authenticated Session affinity. Product Phase 16 adds Worker reservation, shared Origin cooldown, bounded request permits, sticky/fail-closed routing, and durable scheduler state. The repository still lacks the Phase 9 Discovery Engine, so no Phase 10 completion or discovery integration claim is made; the real browser and platform gates remain explicit. Downloader, archive runtime, replay execution, rewrite, and target-site acceptance remain outside the Phase 16 scope.

The dependency path is Apps -> contract/Application Service -> Core ports and pure policy -> SQLite/platform adapters. Desktop/CLI never access Queue tables directly. SQLite owns short `BEGIN IMMEDIATE` transactions and persistent uniqueness/history; the Queue package owns deterministic behavior without SQLite/Electron/browser/network dependencies.

Accepted production decisions are ADR-001 through ADR-059 for the current worktree. Product Phase 8 is verified; Product Phase 9 — Link Discovery and SPA Support remains an open prerequisite. Phase 10 interaction work is partial, Phase 11 Secret Store work is locally implemented but conditional on the existing gate, Phase 12 implementation is present with its real-browser validation limitation, and Phase 13/14 records retain their historical scope and gates. Phase 15 Proxy Manager and Health Monitor and Phase 16 Worker Pool/rate scheduling are implemented within their declared boundaries; exact clean-HEAD and later target-site gates remain explicit. None of these phases bypasses discovery or claims later-phase behavior.
