# Production Architecture

## Product Phase 8 Browser/Rendering foundation and Phase 10 interaction foundation

The current architecture adds `packages/browser-runtime` as the sole Playwright adapter, `packages/rendering` as browser-independent orchestration, and `packages/secrets` as the privileged Secret Store adapter boundary. Archive Core owns ports/models, Application Service owns Queue/Lease/Checkpoint/Fencing and metadata-only Secret orchestration, SQLite schema 7 owns Render and Interaction ledgers, and contract 1.7 carries Browser/Render/Interaction/Secret metadata commands. Read [Browser Runtime](BROWSER_RUNTIME.md), [Human-Paced Interaction](BROWSER_INTERACTION.md), [Secret Store](SECRET_STORE.md), [Portable Vault](PORTABLE_VAULT.md), [Lifecycle](BROWSER_LIFECYCLE.md), [Rendering Engine](RENDERING_ENGINE.md), [Stability](RENDER_STABILITY.md), [Runtime Network Policy](RUNTIME_NETWORK_POLICY.md), [Render Results](RENDER_RESULTS.md), [Phase 8 security review](PHASE_08_SECURITY_REVIEW.md), [Phase 10 security review](PHASE_10_SECURITY_REVIEW.md), and [Phase 11 security review](PHASE_11_SECURITY_REVIEW.md).

The Phase 10 foundation adds Interaction Profile/Plan/Trace schema 1 and bounded browser interaction. Product Phase 11 adds Secret Reference/Vault/Envelope version 1, a dedicated encrypted store, scoped access, redaction, safe exports, diagnostics, and temporary cleanup. The repository still lacks the Phase 9 Discovery Engine, so no Phase 10 completion or discovery integration claim is made; the Phase 11 implementation is therefore recorded as conditional rather than as a false full-gate claim. Authentication, session, OTP, proxy, downloader, and Worker pool work remain outside scope.

The dependency path is Apps -> contract/Application Service -> Core ports and pure policy -> SQLite/platform adapters. Desktop/CLI never access Queue tables directly. SQLite owns short `BEGIN IMMEDIATE` transactions and persistent uniqueness/history; the Queue package owns deterministic behavior without SQLite/Electron/browser/network dependencies.

Accepted production decisions are ADR-001 through ADR-050. Product Phase 8 is verified; Product Phase 9 — Link Discovery and SPA Support remains an open prerequisite. Phase 10 interaction work is partial, and Product Phase 11 Secret Store work is locally implemented but conditional on the existing gate; neither phase bypasses discovery or claims later-phase behavior.
