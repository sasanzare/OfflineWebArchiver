# Production Architecture

## Product Phase 14 OTP/Picker over the Phase 8–13 foundation

The current architecture adds `packages/browser-runtime` as the sole Playwright adapter, `packages/rendering` as browser-independent orchestration, and `packages/secrets` as the privileged Secret Store adapter boundary. Archive Core owns ports/models and the Phase 13/14 pure contracts, Application Service owns Queue/Lease/Checkpoint/Fencing and metadata-only Secret/Session/Run-state/OTP orchestration, SQLite schema 9 owns Render, Interaction, Session, and Crawl Run metadata ledgers, and contract 1.10 carries the validated metadata surface. Read [Browser Runtime](BROWSER_RUNTIME.md), [Authentication Sessions](AUTHENTICATION_SESSIONS.md), [Trust Zones and IPC](TRUST_ZONES_AND_IPC.md), [Network Replay](NETWORK_REPLAY.md), [Strict Offline Mode](STRICT_OFFLINE_MODE.md), [Service Worker Policy](SERVICE_WORKER_POLICY.md), [Canonical Path Safety](CANONICAL_PATH_SAFETY.md), [Worker/Network Concurrency](WORKER_NETWORK_CONCURRENCY_CONTRACT.md), [Human-Paced Interaction](BROWSER_INTERACTION.md), [Secret Store](SECRET_STORE.md), [Portable Vault](PORTABLE_VAULT.md), [Lifecycle](BROWSER_LIFECYCLE.md), [Rendering Engine](RENDERING_ENGINE.md), [Stability](RENDER_STABILITY.md), [Runtime Network Policy](RUNTIME_NETWORK_POLICY.md), [Render Results](RENDER_RESULTS.md), [Phase 8 security review](PHASE_08_SECURITY_REVIEW.md), [Phase 10 security review](PHASE_10_SECURITY_REVIEW.md), [Phase 11 security review](PHASE_11_SECURITY_REVIEW.md), [Phase 12 security review](PHASE_12_SECURITY_REVIEW.md), [Phase 13 security review](PHASE_13_SECURITY_REVIEW.md), and [Phase 14 security review](PHASE_14_SECURITY_REVIEW.md).

The Phase 10 foundation adds Interaction Profile/Plan/Trace schema 1 and bounded browser interaction. Product Phase 11 adds Secret Reference/Vault/Envelope version 1, a dedicated encrypted store, scoped access, redaction, safe exports, diagnostics, and temporary cleanup. Product Phase 12 adds Session metadata/storage-state/affinity schema 1, headed user-driven login, protected Storage State, fresh restore validation, explicit reauthentication, and safe CLI/Desktop controls. Product Phase 13 adds the all-request authentication allowlist, separate Crawl Run state, versioned replay/offline and Service Worker policies, canonical path/symlink boundaries, command allowlisting, concurrency contracts, and acceptance metrics. Product Phase 14 adds the versioned Locator/Login Flow contract, temporary page-local Picker, and visible OTP state machine without SMS/CAPTCHA automation or sensitive persistence. The repository still lacks the Phase 9 Discovery Engine, so no Phase 10 completion or discovery integration claim is made; the real browser and platform gates remain explicit. Proxy, downloader, archive runtime, replay engine, and Worker Pool work remain outside scope.

The dependency path is Apps -> contract/Application Service -> Core ports and pure policy -> SQLite/platform adapters. Desktop/CLI never access Queue tables directly. SQLite owns short `BEGIN IMMEDIATE` transactions and persistent uniqueness/history; the Queue package owns deterministic behavior without SQLite/Electron/browser/network dependencies.

Phase 10 interaction work is partial, Phase 11 Secret Store work is locally implemented but conditional on the existing gate, Phase 12 implementation is present with its real-browser validation limitation, Phase 13 is partial pending browser/platform evidence, and Phase 14 focused OTP/Picker implementation is present with the same prerequisite gate; none of these phases bypasses discovery or claims later-phase behavior. The next user-requested phase is Phase 15 Proxy Manager and Health Monitor.
