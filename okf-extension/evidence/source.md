# Source Evidence

This authored extension guide describes repository source evidence. Canonical evidence identifiers are indexed in `okf-extension/registry/evidence.json`; each path points to an immutable-in-scope repository source instead of a copied artifact.

Official Concepts expose reader-facing provenance through `sources` and may bridge selected records with `owa.evidence_ids`.

Phase 10 source evidence is indexed as `OKF-EV-P10-INTERACTION`,
`OKF-EV-P10-TRACE`, and `OKF-EV-P10-INTERFACES`; each remains `PARTIAL` because
the production discovery gate is not available in the current baseline.
