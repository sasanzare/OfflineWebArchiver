# Runtime Evidence

This authored extension guide records that the real Electron smoke verifies the local Windows renderer-to-Core path. Product Phase 2 runtime evidence remains linked as historical evidence and is not a production dependency.

Evidence identity and paths remain authoritative in `okf-extension/registry/evidence.json` during the compatibility period.

`OKF-EV-P10-BROWSER` extends the runtime evidence with the local Chromium
interaction fixture. `OKF-EV-P10-DISCOVERY-GATE` is a blocked audit record, not
runtime discovery evidence.
